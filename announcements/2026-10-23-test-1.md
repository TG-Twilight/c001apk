# 欢迎来到 c001apk 小助手

这是一篇用于验收公告功能的**测试公告**，不代表应用更新或正式服务通知。

## 本次检查什么

- 公告列表能否显示标题、摘要和未读状态。
- 点开后能否加载 Markdown，并展开阅读全文。
- 阅读后再次启动，是否保持已读且不重复弹出。
- 已打开的正文能否在本地缓存中复用。

> 普通公告只进入小助手；标记为重要的公告才会首次弹窗提醒。

## Markdown 示例

| 内容 | 展示方式 |
| --- | --- |
| 标题与列表 | 分段阅读 |
| **加粗**与 *斜体* | 强调重点 |
| `行内代码` | 保留原文 |

```text
只同步公告表 → 按需获取这一篇正文 → 保留阅读记录
```
