# 从官方酷安导入设备标识

> 现在默认自动取号，不再需要手动导入。自动获取的说明见 [自动获取设备标识](SZLM_AUTO.md)；
> 本文保留为自动获取失败时的兜底流程，入口在 c001apk **我的 → 设置 → 协议与设备 → 设备标识**。

如果浏览动态或评论时反复出现人机验证，可以尝试手动导入官方酷安生成的数盟 ID。

这是自动取号之前的临时方案——在 2026-10-18 的单机样本中，导入后冷启动、重新加载评论正常，约 44 分钟后的复测仍无需验证。

至于有效期和是否要求验证仍然由服务端决定，这不代表永久有效或所有接口均已恢复。

## 1. 打开官方客户端

先安装并正常打开 Android 官方酷安。然后在 c001apk 的导入页点击 **酷安 OAID 界面**，直达官方的 **检查日志和测试** 页面。

<img src="media/device-id/official-test-page.png" width="320" alt="官方酷安的检查日志和测试页面">

该按钮仅打开官方应用的对应页面。未安装官方酷安时会提示先安装；已安装但无法打开时，请确认应用已启用并更新后重试。本说明核对版本为 16.6.4，其他版本入口可能变化。无需 root，无需向 c001apk 提供酷安账号密码。

## 2. 在同一页点击“复制 OAID”5次

向下滚动，找到 **复制 OAID**，在同一个页面内累计点击 **5 次**。（注意不要着急猛戳，慢慢点）前四次是只有 OAID，或提示没有 OAID；第五次才会复制包含多个字段的完整文本。

<img src="media/device-id/official-copy-oaid.png" width="320" alt="向下滚动后的复制 OAID 按钮，需在同一页面累计点击五次">

完整文本应包含以下字段，实际值不要公开：

```text
设备ID: …
ShuzlmID: …
AndroidID: …
UUID: …
```

按钮名称虽然是“复制 OAID”，本方案实际使用的是 **ShuzlmID（数盟 ID）**，不是 OAID、AndroidID 或 UUID。请复制整段文本，不必自行挑出字段。

## 3. 返回 c001apk 粘贴并保存

回到导入页，点击 **粘贴并识别**，或长按输入框粘贴。出现“已识别数盟 ID”后，点击 **保存并应用**。返回内容页刷新即可。

<img src="media/device-id/import-page.png" width="320" alt="c001apk 导入页：获取步骤、图文说明、粘贴识别和保存按钮">

c001apk 只保存提取出的数盟 ID，并替换请求设备编码的首字段；其余复制字段会被忽略，原机型、系统参数、MAC、登录与本地数据均保留。识别成功后会隐藏复制文本，不会在后台自动读取剪贴板。

电脑端使用同一个导入入口，但获取步骤需要先在 Android 官方酷安完成，再自行将文本传到电脑粘贴。跨设备、Windows、Linux 和 iOS 的免验证效果尚未得到完整验证。

## 常见情况

- **提示没有 ShuzlmID：** 可能只复制了普通 OAID。重新进入官方该页，累计点击五次，再粘贴完整文本。
- **数盟 ID 为空：** 正常打开官方酷安稍等后重新复制，不要用 AndroidID、UUID 或随机值代替。
- **保存后又出现验证：** 该标识可能失效，也可能受到账号、网络或接口限制。可以重新获取导入；仍有挑战时使用正常验证流程。
- **旧版本只有“设备标识（SZLM ID）”输入框：** 需要安装包含此导入功能的新版本。本说明随源码维护，不表示旧发行包已经具备自动识别。

标识保存在本机，用于发给酷安的请求。不要将整段文本、真实 ID 或含标识的截图上传到 Issue、聊天群或公开仓库。

新建或手动重置协议参数时，Android 使用本机的厂商、品牌、型号与系统版本；桌面使用固定的一致兼容配置。不会为协议读取 IMEI、硬件序列号、AndroidID 或 OAID，也不再随机拼接机型和系统版本。已有用户参数不会自动重置；安装随机 ID 和已导入的数盟 ID 保持稳定。
